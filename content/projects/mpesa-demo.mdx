Since payment systems are critical for local businesses, I developed a **demo project** showing how to integrate M-Pesa with modern web applications.

## Features
- Payment initiation via M-Pesa API.
- Transaction status callbacks.
- Dashboard for payment history.
- Secure authentication.

## Technologies
- Node.js (API integration)
- Next.js (frontend)
- M-Pesa Daraja API
- TailwindCSS

export const simulateTransaction = async () => {
  const token = await getAuthToken();

  const response = await axios.post(
    'https://sandbox.safaricom.co.ke/', //sandbox env for testing
    {
      ShortCode: '123456', // Replace with your sandbox Paybill number
      CommandID: 'CustomerPayBillOnline',
      Amount: 1000,
      Msisdn: '254712345678', // Safaricom test phone number will be provided during sandboxing
      BillRefNumber: 'TestPayment',
    },
    {
      headers: { Authorization: `Bearer ${token}` },
    }
  );
}
